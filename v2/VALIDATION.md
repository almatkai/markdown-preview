## Coverage that matters

The Markdown oracle includes headings 1–6 and setext, paragraphs/line breaks, CRLF/CR normalization for HTML while raw copies keep original bytes, astral Unicode and JS whitespace including BOM/NBSP/U+0085, code spans/fences/indented and unclosed fences, code quote/entity escaping, blockquotes and nesting, ordered/unordered/tight/loose/nested/task lists, tables/alignment/missing/excess cells/escaped pipes, emphasis/strong/strike, explicit/reference/autolinks/email, URL query/space/backslash/Unicode encoding, images/alt/title/reference images/nesting, raw HTML/comments/inline raw blocks, HTML entities and escaped entities, trailing spaces and exact source navigation/copies. Copy HTML includes raw HTML as the source does; it is never used as the preview's unsafe HTML input.

Capabilities are fresh and session bound. Tests reject forged/stale/cross-session and discarded-clone IDs, and ensure malformed callback/submit maps do not consume valid actions. Clear/Back/Preview invalidate superseded callbacks; the textarea ID remains stable. Refresh/search/load-more mint no new capabilities and cannot revive IDs through discarded state clones. NativeSessions tests cover real annotation/launch/dispatch/dispose, uninstall rejection, independent drafts, the 128-session limit, clear, in-flight copy serialization, heartbeat while busy and stale queued copies. Copy intent is checkpointed before await; cancellation, null/boolean/malformed/contradictory acknowledgements and transport errors produce explicit uncertainty, never false success, private errors or automatic retries. Acknowledged output survives later failed calls. Strict positive object acknowledgement is tested independently and at the actual SDK boundary.

No source-required persistence exists: the adapter does not read/write storage or migrate legacy data. Actual unchanged SDK tests plus a 30-way concurrent transaction test confirm process-atomic updates, unknown-key preservation and corrupt JSON rejection for future callers. Known typed extension settings do not exist in this source; no settings schema or persistence was invented.
